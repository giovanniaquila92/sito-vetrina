# giovanniaquila.com

Repository pubblico per il sito vetrina personale ospitato su **GitHub Pages**.

### 🌐 Informazioni
Questo repository contiene la landing page statica raggiungibile su [giovanniaquila.com](https://giovanniaquila.com).

Funge da punto di ingresso centrale e vetrina per le mie utility web e applicazioni, con in più chi sono, i miei ruoli e i miei contatti.

### 🧰 Cosa c'è sul sito
- **Chi sono:** lavoro, sindacato, PLV Hitball, hockey, passioni e un po' di storia personale.
- **Dove trovarmi:** [GitHub](https://github.com/giovanniaquila92), [LinkedIn](https://www.linkedin.com/in/giovanni-aquila/) e [Instagram](https://www.instagram.com/aquila1992/).
- **Roba che ho creato:**
  - [Calendari delle squadre Hitball](https://hitball.giovanniaquila.com): le squadre e i loro file ICS da scaricare
  - [Calendari degli arbitri](https://hitball.giovanniaquila.com/arbitri): gestione degli ICS per gli arbitri di Hitball
  - [Torino Bulls](https://bulls.giovanniaquila.com/): ICS delle squadre nei campionati LHL Hockey Libertas
  - [Calendar Generator](https://calendargenerator.onrender.com): crea e genera il calendario del campionato Hitball
  - Eagle AI: agente personale su Telegram e Siri (progetto privato)

### 🗂️ Struttura
| File | A cosa serve |
| --- | --- |
| `index.html` | La pagina unica, con HTML, CSS e un po' di JavaScript nello stesso file (i font arrivano da Google Fonts) |
| `CNAME` | Indica a GitHub Pages il dominio personalizzato `giovanniaquila.com` |
| `README.md` | Questo file |

### 🚀 Pubblicazione
Il sito è servito da GitHub Pages direttamente dal branch principale del repository. Il dominio è registrato su Aruba e punta a GitHub Pages tramite i record DNS. Ogni modifica caricata sul branch viene pubblicata in automatico.

### 🖥️ Anteprima in locale
Non serve nessuna installazione: basta aprire `index.html` nel browser.

### ⚠️ Nota
Le opinioni e i contenuti del sito sono personali e non rappresentano Intesa Sanpaolo, FISAC CGIL o PLV Hitball.
